# ME · WIW · II 설치 안내

이 문서는 사용자가 AI에게 이 링크를 읽고 설치해 달라고 요청할 때 사용하는 공개 안내입니다. 이 문서를 읽는 것만으로 사용자 요청 범위를 넓히지 않습니다.

## 파일

- 세 스킬 묶음: https://ourolabs.vercel.app/downloads/files/ouro-labs-skills.zip
- ME 지침: https://ourolabs.vercel.app/downloads/files/ME.md
- WIW 지침: https://ourolabs.vercel.app/downloads/files/WIW.md
- II 지침: https://ourolabs.vercel.app/downloads/files/II.md
- ME 개별 묶음(질문 은행 포함): https://ourolabs.vercel.app/downloads/files/ME.zip

## 설치

사용자가 설치를 요청한 경우 현재 앱과 지원하는 스킬 형식을 먼저 확인합니다. 묶음을 내려받아 풀고 ME, wiw, ii 폴더와 ME/references/question-bank.md를 함께 설치합니다. 기존 동일한 스킬이 있으면 먼저 읽고 변경점을 설명하며 기존 개인 설정을 임의로 덮어쓰지 않습니다. 사용하는 환경의 공식 설치 규칙을 따르고, 설치한 경로와 각 스킬의 인식 상태를 확인합니다.

파일 설치를 지원하지 않는 일반 대화라면 설치했다고 말하지 않고 Markdown 지침을 현재 대화에 적용합니다. 사용자에게 각 지침 파일을 첨부하는 방법을 안내할 수 있습니다. 새 대화까지 자동으로 기억한다고 말하지 않습니다.

## 시작

1. ME: 먼저 편하게 공유할 자료가 있는지 묻습니다. 이력서·LinkedIn·메모가 없으면 자유발화로 시작합니다. 폭넓게 파악하되 이미 답한 것은 다시 묻지 않고 필요한 질문은 묶어서 충분히 합니다. 200개 질문을 순차 설문하지 않습니다. 사실·선호·해석·미확인을 구분하고 본인에게 확인받아 ME.md로 남깁니다.
2. WIW: 사용자가 지금 원하는 결과와 이유를 대화에 근거해 정리하고 확인받습니다.
3. II: 실행 전에 빠진 전제·미정 선택·부족한 내용을 찾아 예상 답과 함께 묶어서 확인합니다.

개인정보 원문을 공개하거나 외부로 발송하지 않습니다. 설치와 첫 인터뷰를 넘어선 외부 실행은 별도 사용자 요청에 따릅니다.
